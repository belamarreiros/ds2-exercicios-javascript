Fundamentos da Web

Página Estática

Uma página estática é uma página que possui um conteúdo fixo. Quando o usuário acessa a página, o servidor envia os arquivos prontos para o navegador, sem precisar gerar um conteúdo diferente para cada acesso.

Exemplo real: uma página simples de apresentação de uma empresa, como informações sobre a empresa, contato e endereço.

Página Dinâmica

Uma página dinâmica é uma página que pode monstrar conteúdos diferentes dependendo do usuário ou das informações disponíveis. Nesse caso, o servidor pode processar os dados e montar o conteúdo antes de enviar a resposta para o navegador.

Exemplo real: o Instagram, que apresenta conteúdos diferentes para cada usuário de acordo com sua conta e seus dados.

Caminho básico entre navegador, servidor e resposta:

  1. O usuário acessa uma página pelo navegador.
  2. O navegador envia uma requisição para o servidor.
  3. O servidor recebe e verifica o que foi solicitado.
  4. O servidor busca ou gera o conteúdo solicitado.
  5. O servidor envia uma resposta de volta para o navegador.
  6. O navegador recebe a resposta e apresenta a página ao usuário.
